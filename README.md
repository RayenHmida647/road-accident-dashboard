\# 🚦🚦🚦     Road Accident Analysis Dashboard (2021–2022)   🚦🚦🚦



\##  Project Overview



This project presents a Road Accident Analysis Dashboard built to analyze road accident data for the years 2021 and 2022.



The objective is to identify key trends, generate performance indicators (KPIs), and provide actionable insights to improve road safety strategies.



The dataset is stored in an Excel file (.xlsx) format.



---





\## 📈 Key Performance Indicators (KPIs)



\### 🔹 Primary KPIs



\- Total Casualties

\- Casualties by Accident Severity (Fatal, Serious, Slight)

\- Maximum Casualties by Vehicle Type



\### 🔹 Secondary KPIs



\- Casualties by Vehicle Type

\- Monthly Trend Comparison (Year-over-Year)

\- Maximum Casualties by Road Type

\- Distribution of Casualties by Road Surface

\- Casualties by Area and Time (Day/Night)
